# Prerequisites

## Required

- Java basics: records, `Map`, `List`.
- The Message Translator idea, ideally from the plain Java version of this pattern.

## Explicitly not required

- Docker or a message broker. Camel runs in memory.
- Earlier Camel experience. The dependencies page explains the words used.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
