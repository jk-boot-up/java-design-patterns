# Prerequisites

## Required

- Java basics: records, maps, threads, `BlockingQueue`.
- `CompletableFuture` at the level of waiting for a result.

## Explicitly not required

- JMS or RabbitMQ. Queues are in memory.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
