# Prerequisites

## Required

- Java basics: classes, records, methods.
- What a message is: a small piece of data one part of a system sends to another.

## Explicitly not required

- A message broker such as Kafka or RabbitMQ. The messages here are plain Java objects.
- Any integration framework. Camel and Spring Integration are named, not used.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
