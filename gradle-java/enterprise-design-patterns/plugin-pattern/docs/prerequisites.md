# Prerequisites

## Required

- Java basics: interfaces, classes.
- What a `.properties` file is: lines of `key=value`.

## Explicitly not required

- Reflection in depth. One call, `Class.forName(...)`, is explained where it is used.
- Spring or any framework.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
