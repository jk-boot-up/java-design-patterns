# Prerequisites

## Required

- Java basics: interfaces, lists, streams, lambdas.
- A little SQL: `SELECT`, `WHERE`, `AND`.

## Explicitly not required

- A database. SQL is produced and printed, not executed.
- JPA or any query library.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
