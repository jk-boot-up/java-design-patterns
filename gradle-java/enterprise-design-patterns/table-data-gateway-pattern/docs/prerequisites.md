# Prerequisites

## Required

- Java basics: classes, records, exceptions.
- A little SQL: `SELECT`, `UPDATE`, `WHERE`.

## Explicitly not required

- A database server. H2 runs inside the program, in memory.
- JDBC in depth. `PreparedStatement` and `ResultSet` appear only inside the gateway.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
