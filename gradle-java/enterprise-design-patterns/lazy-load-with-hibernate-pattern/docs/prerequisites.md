# Prerequisites

## Required

- Lazy Load: the hand-built version this project pairs with.
- What a database session is, in one sentence: the connection an object loads through.

## Explicitly not required

- No Spring. Hibernate is used directly.
- No prior Hibernate. Two annotations and one query language are introduced as they appear.
- No installed database. H2 runs inside the test.

## What you will need

Java 21. `./gradlew run` works offline.
