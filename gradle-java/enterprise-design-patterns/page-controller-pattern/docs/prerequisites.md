# Prerequisites

## Required

- Java basics: classes, interfaces, exceptions.
- HTTP basics: a path, a query string, status codes 200, 400, 401, 404, 500.

## Explicitly not required

- Servlets or Spring MVC. The JDK's own `HttpServer` is used.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
