# Prerequisites

## Required

- Java basics: classes, exceptions.
- HTTP basics: a request, a response, a status code.

## Explicitly not required

- Servlets or Spring. The JDK's `HttpServer` is used.
- Real mobile networks. Round trips are counted and multiplied by 80 ms.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
