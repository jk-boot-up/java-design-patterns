# Prerequisites

## Required

- Java basics: records, sealed interfaces, `switch` on types.
- A little SQL: tables, columns, `SELECT`, `NULL`.

## Explicitly not required

- JPA or Hibernate. The mapping is written by hand so it can be read.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
