# Problem Statement

## The scenario

The shop sells books, electronics and food, each with its own details.

## The naive version

A table per kind of product makes every question about all products search
every table.

## What this project must deliver

- Table-per-class and its UNION, captured from Hibernate.
- Single table and its plain select.
- Rows loaded as their own classes.
- A new type as one class and one column.
- Empty cells, and NOT NULL refused.
- Every printed result asserted by a test.
