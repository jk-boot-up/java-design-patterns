# Prerequisites

## Required

- Java basics: classes, inheritance, annotations.
- SQL basics: tables, columns, NULL.
- The Single Table Inheritance idea, ideally from the plain Java version of this pattern.

## Explicitly not required

- A database server. H2 runs in memory.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
