# Prerequisites

## Required

- Java basics: classes, annotations.
- HTTP requests, query parameters and status codes.
- The Page Controller idea, ideally from the plain Java version of this pattern.

## Explicitly not required

- Earlier Spring experience. The dependencies page explains the annotations used.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
