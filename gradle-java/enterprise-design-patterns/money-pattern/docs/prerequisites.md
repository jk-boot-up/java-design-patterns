# Prerequisites

## Required

- Java basics: classes, methods, `long` and `double`.
- What `equals` and `hashCode` are for.

## Explicitly not required

- Any money library. The class is written from scratch so every line can be read.
- Accounting knowledge beyond what VAT and a discount are.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
