# Prerequisites

## Required

- Unit of Work: the hand-built version this project pairs with.
- What a Spring bean is, in one sentence: an object Spring creates and wires for you.

## Explicitly not required

- No web. There is no controller.
- No prior Spring. `@Service` and `@Transactional` are introduced as they appear.
- No installed database. H2 runs inside the run.

## What you will need

Java 21. `./gradlew run` works offline.
