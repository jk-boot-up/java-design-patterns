Broker

Description

The first two lines are what a viewer sees above the fold, so they carry the hook rather than the boilerplate.

Broker pattern in Java: a broker sits between clients and services: services register with it by name, clients call it by name, and the broker finds the service, forwards the call and returns the answer, like an old hotel switchboard operator. Explained with an online store checkout that calls a stock service and a price service running as small web servers. We watch hard-coded addresses break, route calls through a broker, move a service without touching the checkout, and spread calls across several copies. We finish with the bill. Call services by name, and let the broker know where they live.
