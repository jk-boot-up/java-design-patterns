# Prerequisites

## Required

- Java basics: classes, interfaces, packages, `import`.
- The idea of an interface as a promise of what a class can do.

## Explicitly not required

- Java's module system, ArchUnit or Spring Modulith. Named, not used.
- Microservices. The last act shows the step towards one, without a network.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
