# Prerequisites

## Required

- Event-Driven Architecture: the hand-built version this project pairs with.
- Docker running. Without it the demo says so and stops, and the Kafka test is skipped.

## Explicitly not required

- No prior Kafka. It is introduced as it appears.
- No installed Kafka: it runs in a container the demo starts and removes.

## What you will need

Java 21. `./gradlew run` works offline.
