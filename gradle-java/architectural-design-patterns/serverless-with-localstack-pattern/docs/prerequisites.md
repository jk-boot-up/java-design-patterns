# Prerequisites

## Required

- Serverless: the hand-built version this project pairs with.
- Docker running. Without it the demo says so and stops, and the Lambda test is skipped.

## Explicitly not required

- No AWS account, and no prior Lambda. It is introduced as it appears.
- No installed LocalStack: it runs in a container the demo starts and removes.

## What you will need

Java 21. `./gradlew run` works offline.
