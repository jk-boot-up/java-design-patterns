# Prerequisites

## Required

- Java basics.
- HTML elements and ids.
- The Page Object idea, ideally from the plain Java version of this pattern.

## Explicitly not required

- A browser installed locally. It runs in a container.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- A running container runtime such as Docker Desktop. The demo starts and removes the browser itself.
- About an hour for the session guide.
