# Prerequisites

## Required

- Java basics: interfaces, classes, exceptions.
- What a unit test is, and how JUnit's `assertEquals` works.

## Explicitly not required

- Mockito or any mocking library. The doubles are written by hand.
- A payment provider account.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
