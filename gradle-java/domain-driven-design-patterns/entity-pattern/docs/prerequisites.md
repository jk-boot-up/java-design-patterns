# Prerequisites

## Required

- Java basics: classes, records, `equals` and `hashCode`.
- `HashMap` and `HashSet` at the level of putting in and finding.

## Explicitly not required

- JPA or a database.
- The rest of domain-driven design.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
