# Prerequisites

## Required

- Java basics: HTTP in outline.
- The Secrets Manager idea, ideally from the plain Java version of this pattern.

## Explicitly not required

- Earlier Vault or OpenBao experience. The dependencies page explains the words used.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- A running container runtime such as Docker Desktop. The demo starts and removes OpenBao itself.
- About an hour for the session guide.
