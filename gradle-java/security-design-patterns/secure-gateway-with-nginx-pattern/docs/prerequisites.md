# Prerequisites

## Required

- HTTP methods, paths, headers and status codes.
- The Secure Gateway idea, ideally from the plain Java version of this pattern.

## Explicitly not required

- Earlier NGINX experience. The dependencies page explains the directives used.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- A running container runtime such as Docker Desktop. The demo starts and removes NGINX itself.
- About an hour for the session guide.
