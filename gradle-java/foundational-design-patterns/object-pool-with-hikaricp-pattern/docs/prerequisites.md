# Prerequisites

## Required

- Object Pool: the hand-built version this project pairs with.
- What a database connection is, in one sentence.

## Explicitly not required

- No Spring. HikariCP is used directly.
- No prior HikariCP. Its settings are introduced as they appear.
- No installed database. H2 runs in memory.

## What you will need

Java 21. `./gradlew run` works offline.
