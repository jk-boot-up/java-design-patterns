# Prerequisites

## Required

- Dependency Injection: the hand-built version this project pairs with.
- What an annotation is, in one sentence: a label the framework reads.

## Explicitly not required

- No web. There is no controller.
- No prior Spring. `@Component` is introduced in the first scene.
- No installed database or server.

## What you will need

Java 21. `./gradlew run` works offline.
