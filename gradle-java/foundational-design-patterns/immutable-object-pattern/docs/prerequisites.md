# Prerequisites

## Required

- Java basics: classes, fields, constructors, `final`.
- What a reference is: two variables can point at the same object.
- `HashSet` and `HashMap` at the level of putting things in and finding them.

## Explicitly not required

- Threads. The half-applied sale is shown step by step, without threads.
- Any library. Records and `Map.copyOf` are part of Java.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
