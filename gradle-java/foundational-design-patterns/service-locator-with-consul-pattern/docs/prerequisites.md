# Prerequisites

## Required

- Service Locator: the hand-built version this project pairs with.
- What a network service and a port are, in one sentence.

## Explicitly not required

- No prior Consul. Registration and health checks are introduced as they appear.
- No prior nginx or Docker knowledge beyond running a container.
- No Java library beyond the JDK.

## What you will need

Java 21. `./gradlew run` works offline.
