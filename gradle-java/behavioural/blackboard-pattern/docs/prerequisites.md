# Prerequisites

## Required

- Java basics: interfaces, records, lists, maps, lambdas.
- `Optional` and `Comparator` at a beginner level.

## Explicitly not required

- Any rule engine or AI library.
- Fraud expertise. The rules are deliberately simple.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
