# Prerequisites

## Required

- Java basics: classes, enums, maps.
- `Optional` at the level of `orElseThrow`.

## Explicitly not required

- Any state machine library. The table is one small class.
- The State pattern. It is compared, not required.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
