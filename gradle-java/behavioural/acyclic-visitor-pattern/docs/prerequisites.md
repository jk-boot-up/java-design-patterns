# Prerequisites

## Required

- Java basics: interfaces, records, `instanceof` with a pattern variable.
- The classic Visitor pattern, or at least the idea of an operation kept outside the classes it works on.

## Explicitly not required

- Sealed interfaces and pattern-matching `switch`. They are mentioned as the modern alternative.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
