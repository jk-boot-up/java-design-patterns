Both designs give the same balance. The difference is everything else.
The log is the truth, and the balance is arithmetic over it. That is what makes “why is it 140”, “what was it on the third” and “which customers did that bug touch” answerable at all — and it is also what makes erasure, replay cost and event versioning genuinely hard.
