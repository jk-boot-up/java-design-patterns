# Prerequisites

## Required

- Feature Toggle: the hand-built version this project pairs with.
- Docker running. Without it the demo says so and stops, and the flagd test is skipped.

## Explicitly not required

- No prior flagd or OpenFeature. They are introduced as they appear.
- No installed flagd: it runs in a container the demo starts and removes.

## What you will need

Java 21. `./gradlew run` works offline.
