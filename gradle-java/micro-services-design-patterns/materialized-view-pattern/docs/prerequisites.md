# Prerequisites

## Required

- Java basics: classes, records, maps, lists.
- What an event is: a short message saying something happened.
- The idea of a microservice owning its own data.

## Explicitly not required

- A database or a message broker. Everything runs in memory.
- CQRS or event sourcing. Both are related, and neither is needed here.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
