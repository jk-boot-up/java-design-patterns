# Prerequisites

## Required

- Java basics: JDBC in outline, loops.
- The Sharding idea, ideally from the plain Java version of this pattern.

## Explicitly not required

- Earlier PostgreSQL experience. Plain SQL is used.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- A running container runtime such as Docker Desktop. The demo starts and removes the databases itself.
- About an hour for the session guide.
