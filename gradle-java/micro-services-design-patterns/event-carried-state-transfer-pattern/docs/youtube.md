## Description

The first two lines are what a viewer sees above the fold, so they carry the hook rather than the boilerplate.

```
Event-Carried State Transfer pattern in Java: when data changes, the new data travels in the event itself, so every service that cares keeps its own copy and never calls the owner back, like a change-of-address card with the address on it. Explained with an online store where a customer service owns the addresses and a shipping service prints delivery labels. We watch a thin event force a call back, put the address in the event, see the copy lag behind, and handle events out of order. We finish with the bill: send the new data, not just the news.
```
