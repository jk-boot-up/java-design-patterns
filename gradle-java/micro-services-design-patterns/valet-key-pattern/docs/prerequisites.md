# Prerequisites

## Required

- Java basics: classes, exceptions, byte arrays.
- HTTP basics: PUT, GET and status codes.

## Explicitly not required

- Cryptography. HMAC is used as a black box: same secret, same signature.
- Any cloud account. Storage is a local server.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
