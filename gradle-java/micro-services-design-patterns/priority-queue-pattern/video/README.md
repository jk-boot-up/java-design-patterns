# Priority Queue Pattern — Teaching Video

A narrated, slide-based video built by `./build_video.sh` with the shared videokit library.

| File | What it is |
| --- | --- |
| `priority-queue-pattern-explained.mp4` | the video, 1920×1080 |
| `priority-queue-pattern-explained.m4a` | audio only |
| `priority-queue-pattern-explained.srt` | subtitles |
| `poster.png` | the opening frame |

**Narration:** Piper `en_US-amy-medium`, speed 0.8, longer pauses (the approved `amy-slow` voice). Scenes are generated from `../pattern.toml` into `scenes.py`.

Suggested description:

> Priority Queue pattern in Java, explained with an online store warehouse
> where pickers work through orders and same-day orders must catch the
> courier's van. Urgent messages overtake routine ones however long those
> have waited, while a share of capacity is kept so routine work still gets
> done, like airport fast-track with an officer always on the ordinary lane.
> We watch first come, first served miss the van, add a priority queue,
> survive a flood of standard orders, and prevent starvation with a reserved
> share. We finish with the bill.
