Watch the four promises above, not the boxes.
Both consumers do the same job and both try to spot the duplicate. What changes is where the memory of “I have handled this” is kept, and whether it is written in the same instant as the work. Moving it into the same commit as the effect buys three of those promises outright — and the fourth is never on offer, because a table of ids cannot grow forever.
