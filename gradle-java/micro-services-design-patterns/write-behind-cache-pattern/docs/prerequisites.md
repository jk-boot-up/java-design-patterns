# Prerequisites

## Required

- Java basics: classes, interfaces, maps and sets.
- What a cache is: a fast copy of data kept in memory.

## Explicitly not required

- Redis or any cache product. The cache is a map.
- Threads or timers. `flush` is called by the demo where a timer would call it.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
