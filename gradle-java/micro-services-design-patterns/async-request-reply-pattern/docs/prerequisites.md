# Prerequisites

## Required

- Java basics: classes, records, maps.
- HTTP basics: a request, a response, and a status code such as 200 or 404.

## Explicitly not required

- A web server. The three endpoints are plain Java methods.
- Threads. A pretend clock stands in for time passing.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
