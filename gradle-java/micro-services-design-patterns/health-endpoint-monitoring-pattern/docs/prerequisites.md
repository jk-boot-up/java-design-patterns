# Prerequisites

## Required

- Java basics: classes, records, lists, lambdas.
- HTTP status codes 200 and 503.
- The idea of running several copies of a service behind a load balancer.

## Explicitly not required

- Kubernetes or Spring Boot. Probes and Actuator are named, not used.
- A web server. Endpoints are static methods.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
