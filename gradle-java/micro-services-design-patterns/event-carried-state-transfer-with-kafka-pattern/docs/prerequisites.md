# Prerequisites

## Required

- Java basics: maps, lists.
- The Event-Carried State Transfer idea, ideally from the plain Java version of this pattern.

## Explicitly not required

- Earlier Kafka experience. The dependencies page explains the words used.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- A running container runtime such as Docker Desktop. The demo starts and removes Kafka itself.
- About an hour for the session guide.
