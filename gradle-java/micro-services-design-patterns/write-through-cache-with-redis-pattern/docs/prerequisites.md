# Prerequisites

## Required

- Java basics: exceptions, JDBC in outline.
- The Write-Through Cache idea, ideally from the plain Java version of this pattern.

## Explicitly not required

- Earlier Redis or PostgreSQL experience. The dependencies page explains what is used.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- A running container runtime such as Docker Desktop. The demo starts and removes Redis and PostgreSQL itself.
- About an hour for the session guide.
