# Prerequisites

## Required

- Java basics: HTTP in outline.
- The Valet Key idea, ideally from the plain Java version of this pattern.

## Explicitly not required

- An AWS account. LocalStack plays S3 on your machine.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- A running container runtime such as Docker Desktop. The demo starts and removes LocalStack itself.
- About an hour for the session guide.
