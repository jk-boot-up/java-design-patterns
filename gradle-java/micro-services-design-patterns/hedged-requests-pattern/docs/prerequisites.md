# Prerequisites

## Required

- Java basics: records, `Callable`, `ExecutorService`.
- What a percentile is: the 99th percentile is slower than 99% of calls.

## Explicitly not required

- A network. Replicas are simulated, and in act four they are threads.

## What you will need

- A Java 21 JDK. The Gradle wrapper downloads everything else.
- About an hour for the session guide.
