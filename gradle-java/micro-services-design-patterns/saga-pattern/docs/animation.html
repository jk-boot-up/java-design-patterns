Every version of this checkout calls the same five services in the same order. What changes is what it can promise afterwards: four calls in a try block promise nothing at all; a saga gets the shop back and says so out loud — but the undo leaves two lines in the ledger rather than none, the undo can itself be refused, and a sent email cannot be undone at any price.
