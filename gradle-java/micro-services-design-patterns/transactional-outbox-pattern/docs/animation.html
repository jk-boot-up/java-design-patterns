Watch the four promises above, not the boxes.
Both versions save the same order and send the same message. What changes is what they can promise afterwards: two lines promise nothing, because a process can die in the gap and leave no trace that a message was owed. Moving the message into the database buys atomicity, an outage-proof checkout and eventual delivery — and pays for all three with a duplicate that nothing here can remove.
