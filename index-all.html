How to run any project

Open the project folder and run ./gradlew run for the demo or ./gradlew test for the tests. Plain projects need only a Java 21 JDK. Framework projects say in their README and docs/dependencies.md what else they need; most that use real infrastructure need Docker running, and start and stop their own containers. Videos are built with video/build_video.sh and are not committed.
